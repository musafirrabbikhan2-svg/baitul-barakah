========================================================
বাইতুল বারাকাহ সমিতি — website এ Google Sheet যুক্ত করার নিয়ম
========================================================

এই কাজটা একবার করে দিলে, পরবর্তীতে সদস্য তালিকা বা নিয়মাবলী
বদলাতে চাইলে শুধু Google Sheet এ গিয়ে এডিট করলেই হবে —
কোনো কোড/ফাইল টাচ করা লাগবে না।

মোট ২টা কাজ করতে হবে:
  ১) একটা Google Sheet বানানো (সদস্য তালিকার জন্য একটা, নিয়মাবলীর জন্য একটা ট্যাব)
  ২) সেই Sheet টা "publish to web" করে একটা লিংক নিয়ে config.js ফাইলে বসানো


--------------------------------------------------------
ধাপ ১: Google Sheet বানান
--------------------------------------------------------

1. sheets.google.com এ যান, নতুন একটা Sheet বানান।
   নাম দিন: "Baitul Barakah - Website Data"

2. নিচের দিকে ২টা ট্যাব বানান (Sheet এর নিচে + বাটনে ক্লিক করে):
   - একটার নাম দিন: Members
   - আরেকটার নাম দিন: Rules

3. "Members" ট্যাবে প্রথম সারিতে (row 1) ঠিক এই ৩টা হেডার বসান
   (বাংলায়, ঠিক এভাবে লিখতে হবে, বানান একই রাখতে হবে):

   নাম | পদবী | এলাকা

   তারপর ২য় সারি থেকে আপনার সদস্যদের তথ্য দিন। যেমন:

   মাওলানা সিয়াম আহমেদ | সভাপতি | খোলামোড়া, কামরাঙ্গীরচর
   মুফতি জুনায়েদ রায়হান | সেক্রেটারী | খোলামোড়া, কামরাঙ্গীরচর
   ... (এভাবে সব সদস্য)

   পরামর্শ: মোবাইল নম্বর ও পূর্ণ ঠিকানা এই Sheet এ না রাখাই ভালো,
   কারণ এই তথ্য ওয়েবসাইটে সবাই দেখতে পাবে। শুধু নিজেদের
   অভ্যন্তরীণ হিসাবের জন্য আলাদা Sheet এ এগুলো রাখুন।

4. "Rules" ট্যাবে প্রথম সারিতে এই ২টা হেডার বসান:

   শিরোনাম | বিস্তারিত

   তারপর ২য় সারি থেকে নিয়মগুলো দিন। যেমন:

   সদস্যপদ | সমিতির সদস্য হতে হলে পরিচালনা কমিটির অনুমোদন লাগবে।
   মাসিক চাঁদা | প্রতি মাসে নির্ধারিত পরিমাণ চাঁদা জমা দিতে হবে।
   ... (এভাবে যতগুলো নিয়ম আছে)

   নতুন নিয়ম যোগ করতে চাইলে শুধু নতুন সারি যোগ করবেন —
   একটা নিয়ম মুছতে চাইলে সেই সারিটা মুছে দিবেন।


--------------------------------------------------------
ধাপ ২: Sheet টা "Publish to web" করুন
--------------------------------------------------------

এটা প্রতিটা ট্যাবের জন্য আলাদাভাবে করতে হবে (Members ও Rules,
মোট ২ বার)।

1. Google Sheet এর উপরে মেনু থেকে: File > Share > Publish to web
   (বাংলায় হলে: ফাইল > শেয়ার করুন > ওয়েবে প্রকাশ করুন)

2. একটা popup আসবে। সেখানে dropdown থেকে:
   - প্রথম dropdown এ সিলেক্ট করুন: "Members" (শুধু এই ট্যাবটা)
   - দ্বিতীয় dropdown এ সিলেক্ট করুন: "Comma-separated values (.csv)"

3. "Publish" বাটনে ক্লিক করুন। Confirm করতে বললে "OK" দিন।

4. এখন একটা লিংক (URL) দেখাবে — এটা কপি করুন।
   এই লিংকটাই আপনার "Members" এর CSV লিংক।

5. একই কাজ আবার করুন, কিন্তু এবার প্রথম dropdown এ
   "Rules" সিলেক্ট করুন। এই দ্বিতীয় লিংকটা হলো "Rules" এর CSV লিংক।

এখন আপনার কাছে ২টা লিংক আছে — একটা Members এর, একটা Rules এর।


--------------------------------------------------------
ধাপ ৩: লিংক দুইটা config.js ফাইলে বসান
--------------------------------------------------------

1. এই ফোল্ডারের ভেতরে js ফোল্ডারে গিয়ে "config.js" ফাইলটা
   খুলুন (Notepad বা যেকোনো text editor দিয়ে)।

2. এরকম দেখতে পাবেন:

   MEMBERS_CSV_URL: "",
   RULES_CSV_URL: ""

3. দুইটা quote ("") এর মাঝখানে আপনার কপি করা লিংক দুইটা বসান। যেমন:

   MEMBERS_CSV_URL: "https://docs.google.com/spreadsheets/d/....../pub?output=csv",
   RULES_CSV_URL: "https://docs.google.com/spreadsheets/d/....../pub?output=csv"

4. ফাইলটা Save করুন।

5. এখন website এ যদি GitHub এ আপলোড করা থাকে, সেখানেও
   এই বদলানো config.js ফাইলটা re-upload করে দিন
   (আগেরটা মুছে নতুনটা upload করলেই হবে, অথবা GitHub এর
   ওয়েবসাইটে গিয়ে config.js ফাইলে ক্লিক করে পেন্সিল আইকনে
   ক্লিক করে সরাসরি এডিট করা যায়)।

--------------------------------------------------------
ধাপ ক-১: প্রথমে website টা GitHub Pages এ লাইভ করে নিন
--------------------------------------------------------

Client ID এর জন্য আপনার সাইটের আসল লিংক লাগবে
(যেমন: https://yourname.github.io/baitul-barakah/)।
তাই এই ফিচার সেটাপ করার আগে সাইট আগে GitHub Pages এ
লাইভ করে নেওয়া ভালো।


--------------------------------------------------------
ধাপ ক-২: Google Client ID বানান
--------------------------------------------------------

1. console.cloud.google.com এ যান, Google দিয়ে লগইন করুন।

2. উপরে "Select a project" থেকে "New Project" — একটা
   নাম দিন (যেমন "Baitul Barakah Website") — Create করুন।

3. বাম পাশের মেনু থেকে: APIs & Services > OAuth consent screen
   এ যান। "External" সিলেক্ট করে Create করুন। App name,
   আপনার ইমেইল দিয়ে ফর্মটা পূরণ করে Save করে এগিয়ে যান
   (বাকি ধাপগুলোতে ডিফল্ট রেখেই "Save and Continue" দিতে পারেন)।

4. বাম মেনু থেকে: APIs & Services > Credentials এ যান।
   "+ Create Credentials" > "OAuth client ID" ক্লিক করুন।

5. Application type এ "Web application" সিলেক্ট করুন।

6. "Authorized JavaScript origins" এর নিচে "+ Add URI"
   ক্লিক করে আপনার GitHub Pages এর লিংক বসান, যেমন:
   https://yourname.github.io
   (শেষে স্ল্যাশ / দেওয়া যাবে না)

7. "Create" ক্লিক করুন। একটা "Client ID" দেখাবে
   (লম্বা একটা কোড, শেষে ".apps.googleusercontent.com" থাকবে)
   — এটা কপি করে রাখুন।

8. js/config.js ফাইল খুলে GOOGLE_CLIENT_ID: "" এর
   quote এর মাঝখানে এই Client ID বসান।


--------------------------------------------------------
ধাপ খ-১: Apps Script বানান (ভিজিটর লগ রাখতে)
--------------------------------------------------------

1. যে Google Sheet এ আপনার সদস্য তালিকা/নিয়মাবলী আছে,
   সেটাই খুলুন (একই Sheet ব্যবহার করাই সহজ)।

2. উপরের মেনু থেকে: Extensions > Apps Script এ ক্লিক করুন।
   একটা নতুন ট্যাবে Apps Script এডিটর খুলবে।

3. এডিটরে যা লেখা আছে সব মুছে দিন। এই ফোল্ডারে থাকা
   "AppsScript-VisitorLog.gs.txt" ফাইলটা খুলুন, পুরো
   কোড কপি করে Apps Script এডিটরে পেস্ট করুন।

4. উপরে ডিস্কের মতো আইকনে ক্লিক করে Save করুন
   (একটা প্রজেক্টের নাম চাইতে পারে, যা খুশি দিন)।


--------------------------------------------------------
ধাপ খ-২: Web App হিসেবে Deploy করুন
--------------------------------------------------------

1. উপরে ডানপাশে "Deploy" বাটনে ক্লিক করুন > "New deployment"।

2. পাশের গিয়ার (⚙️) আইকনে ক্লিক করে "Web app" সিলেক্ট করুন।

3. নিচে দুইটা dropdown আসবে:
   - "Execute as": "Me" রাখুন
   - "Who has access": "Anyone" সিলেক্ট করুন
   (এটা জরুরি — নাহলে ভিজিটরদের ব্রাউজার থেকে ডাটা পাঠানো যাবে না)

4. "Deploy" ক্লিক করুন। Google আপনাকে permission
   চাইতে পারে — নিজের অ্যাকাউন্ট সিলেক্ট করে Allow দিন
   ("Advanced" > "Go to [project name] (unsafe)" বললে
   ভয় পাবেন না, এটা আপনার নিজের বানানো স্ক্রিপ্ট বলেই এই
   সতর্কবার্তা দেখায়)।

5. একটা "Web app URL" দেখাবে — এটা কপি করুন।

6. js/config.js ফাইলে VISITOR_LOG_URL: "" এর quote এর
   মাঝখানে এই URL বসান।

সব শেষে
--------------------------------------------------------

config.js ফাইল Save করে GitHub এ re-upload করুন।
এখন সাইটে গিয়ে দেখুন উপরে ডানপাশে "Sign in with Google"
বাটন দেখাচ্ছে কিনা। কেউ সাইন-ইন করলে তার নাম/ইমেইল/সময়
আপনার Sheet এর "Visitors" ট্যাবে (automatic তৈরি হবে)
যোগ হয়ে যাবে।

সমস্যা হলে Claude কে বলুন কোন ধাপে আটকেছেন, স্ক্রিনশট
দিলে আরও সহজে সমাধান করা যাবে।


========================================================
যোগাযোগ পেজে Sheet লিংক (Viewer, edit নয়)
========================================================

contact.html এ একটা জায়গা রাখা আছে যেখানে আপনি চাইলে
Sheet টা "শুধু দেখার জন্য" লিংক আকারে যোগ করতে পারেন।

সঠিক Viewer লিংক পেতে:

1. Google Sheet খুলুন। উপরে ডানপাশে "Share" বাটনে ক্লিক করুন।

2. "General access" এর নিচে "Restricted" থেকে বদলে
   "Anyone with the link" সিলেক্ট করুন।

3. তার পাশেই একটা dropdown এ "Editor" লেখা থাকবে —
   সেটা বদলে অবশ্যই "Viewer" করে দিন। (এটা এড়িয়ে গেলে
   যে কেউ আপনার হিসাব বদলে দিতে পারবে — এই ধাপ বাদ দেবেন না)

4. "Copy link" এ ক্লিক করে লিংক কপি করুন।

5. contact.html ফাইলে "এখানে আপনার Viewer লিংক বসান"
   এই লেখার জায়গায় (href="#" অংশে) এই লিংক বসান।

⚠️ এই লিংকে "Viewer" ছাড়া অন্য কিছু (Editor/Commenter)
   কখনো public পেজে যোগ করবেন না।
